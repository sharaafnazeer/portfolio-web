The hardest part of a trader UI isn't the layout — it's keeping the screen
truthful when 8,000 ticks per second are arriving on 30 instruments while a
human is hovering an order ticket they expect to be instantly responsive.

## Architecture highlights

- **Fine-grained reactivity** with Angular Signals. Components subscribe to
  exactly the data fields they need; a price tick only re-renders the cells
  that depend on it.
- **Back-pressure-aware GraphQL subscriptions** that coalesce updates server-
  side based on observed client throughput.
- **WebTransport for hot paths** with WebSocket fallback — a single bi-di
  stream handles auth, subscriptions and order entry.
- **Optimistic order acks** with reconciliation against the FIX gateway so
  traders see immediate UI feedback but never see incorrect filled prices.
- **Offline-first persistence** of the trader's workspace via IndexedDB,
  including layout, watchlists and unsent ticket drafts.
